# Ampere GA104 checks on one RTX 3070 Ti

Read and restored-write checks on 2026-09-28. This is one ASUS RTX 3070 Ti,
driver 595.97, VBIOS 94.04.5a.00.56. It does not set voltages, current
ceilings or clock routing for every Ampere board. Druta still requires the
live getter to echo the layout before a slider is shown.

## NVVDD limits

Public control version `0x00020AC8` and absolute status version `0x00010AC8`
accept mask 1 and reject mask 2. The native packet is the already recognized
1104-byte `0x2080B213` GET. Each of the four NVVDD fields accepted a 6.25 mV
step and restored its original zero delta. Raising vmin from 662.5 mV to
668.75 mV moved the live rail from 675 mV to 681.25 mV, then restoration
returned it. There is no MSVDD record on this adapter.

## Clock-domain controls

Domains 0–9 accept `0xF58938F5` at version `0x000261A4`, with records at
`0x124 + domain * 0x304`. With the core locked at 1500 MHz:

| Control | Field | Result |
|---|---|---|
| 1 | `+0x10C` +15 MHz | Stored. Programmed domains 1, 2 and 21 each rose 15 MHz. |
| 3 | `+0x10C` +15 MHz | Stored. Only programmed domain 2 rose 15 MHz. |
| 5 | `+0x10C` +15 MHz | Stored. Only programmed domain 21 rose 15 MHz. |
| 1 | `+0x114` +15 MHz | Refused, status -1. |
| 0 | `+0x110` +6.25 mV | Stored. vcore and live NVVDD both rose 6.25 mV. |
| 2 | `+0x10C` +100 MHz, memory at 810 MHz | Stored. NVML memory stayed 810. |
| 2 | `+0x10C` +100 MHz, copy load, memory at 9251 MHz | Stored. Private domain 4 and NVML memory both moved to 9351. |
| 9 | `+0x10C` +45 / +90 / +120 MHz under load | Stored. Domain 5 stayed at its 1350 MHz programmed ceiling. |
| 9 | `+0x10C` –15 MHz under load | Stored. Domain 5 stayed at 1350. |
| 9 | `+0x10C` –45 / –90 / –120 MHz under load | Stored. Domain 5 moved 1350 → 1320 / 1275 / 1245, then restored. |

GPU-Z 2.71, read beside these programmed clocks, names domain 1 Crossbar
(1899.1 against 1905), domain 2 SYS (1701.4 against 1695) and domain 21
Video (1772.1 against 1770). Domain 5 at 1350 has no GPU-Z row. It is the
control-9 target and is shown as LTC?, the same role as Turing's LTC, with
the likely grade supplying the question mark. GPU-Z's memory clock is
1187.7 MHz against NVML's 9501, which is eight times the GPU-Z figure.

Every buffer was restored. The idle memory clock does not show control 2's
request; the high memory clock does, one reported megahertz per requested
megahertz. Control 9 moves domain 5 downward from 1350 MHz and does not raise
it. A –15 MHz request is stored and does not change that target. The NVVDD
offset slider uses `+0x110`.

## Core current

Policy 13 reads type `0x0F`, channel 19, 1 mA minimum, 243 A default and
270 A API maximum. The production setter changed 270 A to 269 A and restored
270 A, with stored and effective readback both times. Policy 18 is a 5,001 A
sentinel and is not shown.
